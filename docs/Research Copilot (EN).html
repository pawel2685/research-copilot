Research Copilot
A multi-agent research assistant built with Google ADK: five agents, two of which the system skips when time runs short.
Team: [name A] · [name B] · [name C]
Project overview
The user asks a research question, for example “what are the methods for compressing LLMs?”. The system finds papers on arXiv on its own, summarises them, checks its own claims and writes a short report with sources.
Input
Research question
A question in natural language
Processing
Five agents
Google ADK, hybrid search, context compression
Output
Report with sources
Citations and a verification flag
Goal: find out which component of an agent system gives the most quality for the least time and tokens.

Metrics and research questions
Metrics
  • Recall@k: were the reference papers found
  • Report quality: an LLM judge on a fixed scale and a manual check of a sample
  • Cost: number of LLM calls, tokens and response time
Questions for the report
  • How much quality does each component give relative to its cost in time and tokens?
  • How does quality drop when a small time budget forces the Planner and the Critic to be skipped?
The second question gives a chart of quality against time budget for the full system. We will add the results after the experiments.
